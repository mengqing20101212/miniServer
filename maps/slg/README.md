# SLG 地图输入

此目录接收地图工具导出的 `WorldMap2.tmx` 和 `world-regions.json`。
当前工作区通过本地链接读取公司项目原文件，不修改原文件；大型地图资源不进入 Git。
其他机器请复制地图导出文件，或通过 `-Dslg.scene.map-dir=/绝对路径` 指定目录。

- 当前尺寸：1200×1200，逻辑坐标 0～1199。
- `cellRegionIds[y * width + x]` 决定玩法区域；`regionDefs` 每个区域对应一个场景执行线程。
- 当前地图包含 25 个区域。区域边界不要求与 AOI 方格对齐。
- 服务端读取地表、地表装饰、物体图层，Lake 图块作为水域，后两个图层非零图块作为障碍。
- 图片和装饰展示属性留给前端，不创建百万个常驻格子对象。
